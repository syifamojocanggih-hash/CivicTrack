## 2. Peran Pustaka Berdasarkan Klaster Tematik

1. **Klaster Open Government Data (OGD) & Citizen Participation**:
   - `ansari2022enhancing`, `chokki2022engaging`, `matheus2021design`, `nikiforova2021open`, `zhao2023digital`, `kempeneer2023rethinking`, `jaelani2024pelaksanaan`, `satudatalamongan2024`.
   - Mengkaji pergeseran transparansi e-procurement dari data dump menuju penyajian interaktif yang dapat diakses kognitif oleh masyarakat umum.

2. **Klaster Cognitive Fit Theory & Visual Task Taxonomies (2021–2023)**:
   - `bina2023incorporating` (Ekstensi modern Cognitive Fit untuk visualisasi data, *DSS* 2023).
   - `bacic2022advancing` (Ekstensi eye-tracking untuk cognitive effort & multi-view coordination, *DSS* 2022).
   - `duncan2021task` (Evaluasi empiris elementary lookup vs synoptic spatial tasks dalam kartografi interaktif, *IEEE TVCG* 2021).

3. **Klaster Evaluasi Spasial Partisipatoris (PPGIS, 2023–2024)**:
   - `kytta2023prioritizing` (*LUP* 2023), `johnson2024enhancing` (*LUP* 2024) (Evaluasi PPGIS dalam tata ruang dan persepsi publik terhadap peta tematik).

4. **Klaster Linimasa Proyek, Deviasi Jadwal, Data Hilang & Benchmarking Usability (2021–2025)**:
   - `ayalew2024developing` (*Cogent Eng* 2024) (Earned Value Analysis untuk deviasi kemajuan fisik vs waktu kalender).
   - `tang2024comparative` (*IEEE TVCG* 2024) (Studi komparatif error rate & waktu penyelesaian visualisasi linimasa Gantt chart dan event sequence).
   - `fernstad2022explore` (*IEEE TVCG* 2022) (Visualisasi nilai hilang/missing values dan mitigasi bias inferensi negatif).
   - `ambituuni2025infrastructure` (*ECAM* 2025), `saelawong2024transparency` (*JFC* 2024) (Batas klaim transparansi konstruksi publik CoST; transparansi sebagai enabler antarmuka kognitif, bukan bukti kausal langsung penurunan korupsi).
   - `lewis2021usability` (Wiley 2021), `hyzy2022system` (*JMIR* 2022) (Standarisasi instrumen 10-item System Usability Scale, kurva persentil umum 82.50 = Grade A, 92.5th percentile, \"Excellent\").
